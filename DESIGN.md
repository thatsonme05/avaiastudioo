# Avaia Studio UI direction

- Product: yoga studio booking, membership, and studio administration.
- Identity: grounded, warm, calm, practical, and welcoming; avoid generic SaaS dashboard styling.
- Core palette: `#5D3A24` (primary), `#9C6B3D` (accent), `#FDF8F6` (page surface).
- Supporting surfaces: `#FFFCFA`, borders `#E7DCD4`, readable body text `#45372F`.
- Visual rationale: the dark brown anchors navigation and key actions; the caramel accent is reserved for data visualization and focus; warm near-white surfaces keep long admin sessions comfortable.
- Layout: prioritize the task at each screen, keep tables contained, reflow navigation on mobile, and avoid decoration without functional meaning.
- Accessibility: visible keyboard focus, readable contrast, reduced-motion support, and touch-friendly controls.
