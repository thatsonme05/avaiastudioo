Send Reminders

Send a reminder email to all members who haven't received one yet. Run this daily, or set up a cron job on the server.

How to Enable Email

Fill in the following variables in the .env file, then restart the server:
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=studio@gmail.com
EMAIL_PASS=16-character-app-password
EMAIL_FROM=Avaia Studio <studio@gmail.com>

For Gmail: enable 2FA → Google Account → Security → App passwords → create a new password for "Mail".

How to Enable

1. Sign up at dashboard.midtrans.com
2. Get your Server Key & Client Key
3. Fill in the .env file on the server:
MIDTRANS_SERVER_KEY=...
MIDTRANS_CLIENT_KEY=...
4. Restart the server
